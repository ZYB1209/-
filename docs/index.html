这是在线标注版：支持时间 × 通道范围标注与导出。现有 Python 智能体尚未连接云端，本页不提供自动检测。标注不会自动保存，离开前请导出 JSON 备份；CSV 可交给检测平台使用。

01 · 查看与框选

横轴为原始采样点（从 0 开始），纵轴为环周通道（从 1 到 32，上到下）。拖动框选；同一物理缺陷只标一次，可将轴改为 ALL。

仅为可视化对每个通道减去全记录均值；三轴共用色标。压缩显示时，每个通道的每列保留绝对值最大的响应。原始信号未被修改。时间由采样率换算，未标定长度时不输出米数。

02 · 复核与导出

轴开始点结束点首通道末通道类型备注

JSON 含原始信号的 SHA-256 指纹，支持导回同一份 CSV 继续标注。分享标注时，请同时提供原始 CSV 和标注 JSON。这里的多人协作通过交换文件完成。
