# MFL Lab GitHub Pages

公开网址：https://zyb1209.github.io/-/

这是独立的浏览器端标注界面，不调用模型API，不运行Python检测器，不向GitHub上传用户数据。公开网页不包含API密钥和实验数据。

- 导入带mag_1x…mag_32x、mag_1y…mag_32y、mag_1z…mag_32z列的CSV（2–100000行，64MB以内）。
- 三轴热图拖动框选：从0开始的原始采样点、从1开始的环周通道，起止都包含。可编辑坐标、轴、类型、备注。
- 导出JSON备份，重新载入同一CSV后可导回；SHA-256指纹校验防止错配。导出CSV供独立检测平台使用。
- 没有服务器存储或自动保存，关闭前必须导出。协作者交换原始CSV与标注JSON，不会自动同步。
- 可视化仅减去各通道全记录均值，三轴共用99%抽样绝对响应色标；压缩列保留各通道绝对值最大响应。不是论文中的完整滤波算法。
- 时间按用户输入采样率换算，未接长度/编码器标定。图像框是信号响应范围，不代表断口实际长度。
- 原Python智能体与部署配置位于 ../web-platform/。要在线运行原算法、共享数据和安全调用模型API，仍需要HTTPS后端、访问控制和持久化存储。不要把API密钥写入静态页面。

GitHub Pages 从main分支的/docs目录构建。
